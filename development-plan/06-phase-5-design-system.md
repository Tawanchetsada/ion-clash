## 5.1 ภาษาสีคือภาษาเดียวกันทั้งเกม

จาก UI PDF หน้า 3 สีไม่ใช่การตกแต่ง แต่เป็นการสื่อบทบาทของสาร

| สี | บทบาท | ใช้เมื่อ |
|---|---|---|
| น้ำเงิน `#1F5FAA` | ไอออนบวก | ตลอดเวลา |
| เขียว `#2B8846` | ไอออนลบ | ตลอดเวลา |
| ทอง `#F1BE2D` | ผลิตภัณฑ์ตะกอน | **หลังผ่านการตรวจครบทุกเงื่อนไขเท่านั้น** |
| แดง `#C63C45` | คำตอบผิด เส้นตัดผิด | ชั่วคราว |
| กรมท่า `#082541` | header ปุ่มหลัก ข้อความสำคัญ | ตลอดเวลา |

**กติกาที่ห้ามละเมิด**

- ก่อนตรวจคำตอบ การ์ดไอออนคงสีน้ำเงินหรือเขียว และไม่มีการ์ดสีทองให้เห็นเลย
- สีทองปรากฏเมื่อครบสี่อย่าง จับคู่ถูก + ประจุรวมเป็นศูนย์ + สถานะถูก + ดุลผ่าน
- **ห้ามใช้สีอย่างเดียวสื่อสถานะ** ต้องมีข้อความ ไอคอน และ `aria-live` ร่วมเสมอ
- แอนิเมชันเปลี่ยนสี 150-250 ms และปิดได้เมื่อ `prefers-reduced-motion: reduce`

## 5.2 EquationView กับการแสดงสูตรเคมี

รับ **FormulaAst** จาก Phase 1 ไม่ใช่สตริง ไม่ใช่ HTML

```tsx
<EquationView ast={ast} ariaLabel="ซิลเวอร์คลอไรด์ สถานะของแข็ง" />
```

| ส่วน | render เป็น |
|---|---|
| `{ kind: 'text' }` | ข้อความปกติ |
| `{ kind: 'sub' }` | `<sub>` ตัวห้อย เช่นเลข 2 ใน H2O |
| `{ kind: 'sup' }` | `<sup>` ตัวยก เช่นประจุ 2+ |

**aria-label ภาษาไทย** ต้องสร้างจาก AST เดียวกัน เช่น `Ag+(aq)` อ่านว่า "ไอออนเงิน ประจุบวกหนึ่ง สถานะสารละลาย" ไม่ใช่ให้ screen reader อ่าน "เอจีพลัสเอคิว"

**บนมือถือ** สมการยาวเกินจอได้ ให้เลื่อนเฉพาะแถบสมการที่มี `overflow-x: auto` และมี affordance ให้เห็นว่าเลื่อนได้ ห้ามให้ทั้งหน้าเลื่อนแนวนอน

## 5.3 รายการ component

### layout

| Component | รับ | หน้าที่ |
|---|---|---|
| `AppHeader` | levelId, ปุ่มที่ต้องแสดง | โลโก้ IC · เลขด่าน · ปุ่มหน้าหลัก · ปุ่มวิธีเล่น |

| `StepIndicator` | current 1-5 | วงกลม 5 ขั้นตาม UI PDF หน้า 2 พร้อม `aria-current` |

### game

| Component | รับ | ส่ง event |
|---|---|---|
| `IonCard` | IonInstance, role, selected, disabled, coefficient | SELECT, DRAG_START |
| `CompoundCard` | CompoundDef, isPrecipitate | — (แสดงอย่างเดียว) |
| `IonSlot` | slotId, assignedIon, isDropTarget | PLACE, REMOVE |
| `CoefficientInput` | value, compoundLabel, error | CHANGE, BLUR |
| `EquationView` | FormulaAst | — |
| `SpectatorConnector` | left/right instances, pairs | PAIR, UNDO, RESET |
| `FeedbackPanel` | Feedback หรือ null | RETRY |
| `HintButton` | hintsUsed, disabled | USE_HINT |
| `SaveStatus` | idle/saving/saved/error | RETRY, EXPORT |

### levels

| Component | รับ | ส่ง event |
|---|---|---|
| `LevelGrid` | สรุป 50 ด่าน + save | OPEN_LEVEL |
| `LevelTile` | levelId, status, stars | OPEN |

> `LevelTile` ต้องแยกสามสถานะด้วย**ทั้งสีและสัญลักษณ์** คือผ่านแล้ว ด่านปัจจุบัน และยังไม่ปลดล็อก คนตาบอดสีต้องแยกออก

## 5.4 CoefficientInput

- ค่าเริ่มต้น**เป็นช่องว่าง** ห้ามเติมเลข 1 ให้ล่วงหน้า
- รับเฉพาะจำนวนเต็มบวก 1-9 · trim ช่องว่าง · ปฏิเสธศูนย์ ทศนิยม จำนวนลบ และอักขระอื่น
- ใช้ `inputMode="numeric"` เพื่อให้ iPad เด้งแป้นตัวเลข
- สัมประสิทธิ์ 1 กรอกได้ แต่ตอนแสดงสมการผลลัพธ์ให้**ซ่อนเลข 1**
- มี `<label>` ที่ผูกกับช่องจริง ไม่ใช่ placeholder อย่างเดียว

## 5.5 Responsive

| ลำดับ | อุปกรณ์ | เป้าหมาย |
|---|---|---|
| 1 | iPad แนวนอน | 1024x768 และ 1180x820 เล่นครบทุกขั้นด้วยการแตะและลาก |
| 2 | Desktop | 1280x720 ขึ้นไป ใช้เมาส์และคีย์บอร์ดได้ครบ |
| 3 | มือถือแนวนอน | ขั้นต่ำ 667x375 ลดขนาดการ์ด |
| 4 | มือถือแนวตั้ง | เรียงเป็นส่วน ๆ ห้ามบังคับ 16:9 |

- ใช้ CSS Grid และ Flex เท่านั้นสำหรับโครงหลัก หลีกเลี่ยง absolute
- **ห้ามมี horizontal overflow ระดับหน้า** อนุญาตเฉพาะแถบสมการ
- touch target อย่างน้อย 44x44 CSS px
- ใช้ `clamp()` กับขนาดตัวอักษรและการ์ด และคำนึงถึง `safe-area-inset`
- แถวไอออน 4 ใบบนมือถือแนวตั้งแบ่งเป็น 2 แถว แต่**รักษาลำดับซ้ายไปขวา**

## 5.6 Accessibility

- ใช้ `<button>` จริง ห้ามทำปุ่มด้วย `<div>`
- heading เรียงลำดับถูกต้อง ไม่ข้ามระดับ
- feedback ใช้ `aria-live="polite"` · error สำคัญใช้ `role="alert"` อย่างพอดี ไม่ใส่ทุกที่
- รองรับ zoom 200% โดยข้อความไม่ถูกตัดและฟังก์ชันยังใช้ได้
- modal ต้องมี focus trap · ปิดด้วย Escape · คืน focus ไปปุ่มเดิม · มีชื่อ accessible
- เส้นตัดไอออนผู้ชมต้องมี**รายการข้อความ**ของคู่ที่ตัดแล้วควบคู่ไปกับเส้น SVG

## 5.7 เสียง

ตาม **D-17** ใช้ชุดเสียง **CC0** ของ Kenney ซึ่งไม่ต้องให้เครดิต ใช้เชิงพาณิชย์และการศึกษาได้

| แหล่ง | จำนวน | ลิงก์ |
|---|---|---|
| Kenney UI Audio | 50 เสียง | https://kenney.nl/assets/ui-audio |
| Kenney Interface Sounds | 100 เสียง | https://kenney.nl/assets/interface-sounds |

**เสียงที่ต้องใช้ 5 เสียง**

| จังหวะ | ลักษณะเสียงที่เลือก |
|---|---|
| วางการ์ดลงช่อง | คลิกสั้น เบา ไม่รบกวน |
| ตอบถูก | โทนขึ้นสั้น ๆ |
| ตอบผิด | โทนลงต่ำ ไม่ดังจนน่าตกใจ |
| ตะกอนเกิดเป็นการ์ดทอง | เสียงยืนยันที่หนักแน่นกว่าตอบถูกทั่วไป |
| ผ่านด่าน | เสียงสำเร็จสั้น ๆ ไม่เกิน 1.5 วินาที |

**ข้อกำหนดการใช้งาน**

- แปลงเป็น `.webm` หรือ `.mp3` ให้ไฟล์รวมทั้งหมดไม่เกิน 100 KB
- preload ตอนเข้าหน้าเล่นเกม ไม่ใช่ตอนเปิดเว็บ
- เสียงต้องหยุดทันทีเมื่อปิดสวิตช์ใน `/settings`
- **iOS ต้องมี user gesture ก่อนเล่นเสียงครั้งแรก** ให้ปลดล็อก AudioContext ตอนผู้เล่นกดปุ่มเริ่มเกม ไม่งั้นเสียงจะเงียบทั้งเกมบน iPad
- เสียงเป็นส่วนเสริมเท่านั้น ห้ามใช้เสียงเป็นช่องทางเดียวในการสื่อสถานะ

**เพลงพื้นหลัง** ตั้งค่าเริ่มต้นเป็น **ปิด** เพราะเป็นสื่อที่ต้องใช้สมาธิ ผู้เล่นเปิดเองได้ ถ้าจะใส่ให้เลือกเพลงบรรเลงเบาที่เป็น CC0 จาก OpenGameArt

## Definition of Done

- [ ] ทุก component มี Storybook หรือหน้า `/dev/components` ให้ดูทุกสถานะ
- [ ] ไม่มี component ไหนใน `src/components/` import จาก `src/domain/chemistry/`
- [ ] เทียบกับ UI PDF ทั้ง 12 หน้าแล้วตรงในระดับโครงสร้างและสี
- [ ] ทดสอบ zoom 200% ทุกหน้าหลัก ข้อความไม่ถูกตัด
- [ ] ทดสอบด้วยคีย์บอร์ดอย่างเดียว เข้าถึงทุกปุ่มได้
- [ ] `prefers-reduced-motion` ปิดแอนิเมชันได้จริงทั้งเว็บ
- [ ] เสียงทั้ง 5 เล่นได้บน iPad จริง และปิดจาก `/settings` ได้
