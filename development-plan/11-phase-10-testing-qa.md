## 10.1 Unit test ที่ต้องมี

**โดเมนเคมี** สร้างสูตรครบ 120 คู่ · ดุลทุกอัตราส่วน · แยกตะกอนถูก · จับคู่ไอออนผู้ชมถูก · สมการสุทธิรักษาอะตอมและประจุ · **ทดสอบข้อมูลทั้ง 50 ด่านในลูปเดียว**

**ระบบเซฟ** default ปลดเฉพาะด่าน 1 · ผ่านด่าน 1 แล้ว unlockedLevel เป็น 2 · ผ่านด่าน 50 แล้วไม่เกิน 50 · replay ไม่ลดค่าที่ดีที่สุด · JSON พัง version ผิด ค่านอกช่วง quota error ไม่ crash · export import ได้ข้อมูลเท่าเดิม · migration และ multi-tab merge ไม่ลดความก้าวหน้า

**เกม** เส้นทางสมบูรณ์ของด่านไม่ต้องดุลและด่านต้องดุล · คะแนนและดาว · เพดานการหักคะแนน · คำใบ้ 150 ข้อไม่มีสูตรตะกอน

## 10.3 Fault injection

ต้องทดสอบว่าพังแล้วเกมไม่ล่ม ตาม AC-10

| จำลอง | วิธี | ผลที่ต้องได้ |
|---|---|---|
| localStorage เต็ม | mock ให้ throw QuotaExceededError | แสดง save error เล่นต่อได้ มีปุ่ม export |
| localStorage ถูกปิด | mock ให้ throw SecurityError | เหมือนข้างบน |
| JSON พัง | ใส่ข้อความมั่วลง key | สร้าง backup corrupt ใช้ default แจ้งผู้ใช้ |
| ข้อมูลด่านผิด | แก้ seed ให้ตะกอน 2 ตัว | ไม่เปิดเกม แสดงรหัสข้อผิดพลาด ไม่ล่มทั้งเว็บ |
| Apps Script ล่ม | endpoint คืน 500 | เกมเล่นต่อได้ปกติ event เข้าคิว |
| เน็ตหลุดกลางเกม | offline mode | เล่นด่านที่ค้างจนจบได้ event เข้าคิว (ไม่ทำ PWA ตาม D-18) |

## 10.4 Accessibility

- รันตัวตรวจอัตโนมัติทุกหน้าหลัก ต้องไม่มี violation ระดับ critical หรือ serious
- ทดสอบด้วย **VoiceOver บน iPad** อย่างน้อยหนึ่งรอบเต็มด่าน
- ยืนยันว่าอ่านสูตรเคมีเป็นภาษาไทยถูกต้อง ไม่ใช่สะกดทีละตัวอักษร
- ยืนยัน contrast ของทุกคู่สีที่ใช้จริง ผ่านเกณฑ์ AA
- ยืนยันว่าทุกสถานะมีทั้งสี ข้อความ และไอคอน ตาม AC-13
- zoom 200% แล้วทุกหน้ายังใช้งานได้

## 10.5 ทดสอบบนเครื่องจริง

**ห้ามข้าม** spec ระบุชัดว่าต้องทดสอบบน Safari iPad อย่างน้อย 1 รอบ

- [ ] iPad จริง ลากวางลื่น ไม่มีการเลื่อนหน้าจอโดยไม่ตั้งใจ
- [ ] หมุนจอจากแนวนอนเป็นแนวตั้งกลางเกม แล้ว layout และเส้นตัดยังถูกต้อง
- [ ] แป้นตัวเลขเด้งขึ้นเมื่อแตะช่องสัมประสิทธิ์
- [ ] ปิดแท็บแล้วเปิดใหม่ ความก้าวหน้ายังอยู่
- [ ] เล่นต่อเนื่อง 50 ด่านโดยไม่มีอาการหน่วงสะสม

## 10.6 ตรวจ bundle และความปลอดภัย

- [ ] ไม่มีข้อมูลส่วนบุคคลหรือ secret ใน bundle ตาม AC-14
- [ ] ไม่มี URL Apps Script ใน bundle ที่ build จาก repo
- [ ] level data หลังบีบอัดต่ำกว่า 500 KB
- [ ] localStorage รวมต่ำกว่า 100 KB หลังเล่นครบ 50 ด่าน
- [ ] LCP หน้าแรกและหน้าเลือกด่านไม่เกิน 2.5 วินาทีบนเครือข่ายจำลอง 4G
- [ ] รัน `npm audit` ไม่มีช่องโหว่ระดับ high ขึ้นไป

## Definition of Done

- [ ] AC ทั้ง 15 ข้อผ่าน
- [ ] E2E ผ่านครบทั้ง 3 project
- [ ] เพิ่ม E2E เข้า CI แล้ว (อย่างน้อย project `ipad`)
- [ ] ทดสอบ iPad เครื่องจริงแล้วอย่างน้อย 1 รอบ
- [ ] ไม่มี console error ทั้ง happy path และ error path

## กับดักที่ต้องระวัง

| กับดัก | ผลที่ตามมา |
