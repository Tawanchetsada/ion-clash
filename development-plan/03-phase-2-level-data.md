# Phase 2 · ข้อมูล 50 ด่าน

> **เป้าหมาย:** มีข้อมูลด่านครบ 50 ผ่าน validation อัตโนมัติ และมีเอกสารให้อาจารย์เซ็นรับรอง
> **ต้องรอ:** Phase 1
> **ข้อห้ามจาก spec:** ห้ามสร้างสมการใหม่โดยไม่มีผู้เชี่ยวชาญรับรอง แผนนี้จึงแยกเป็นสองขั้น คือร่างจากกฎการละลาย แล้วส่งให้ตรวจ

---

## 2.1 หลักการ: เก็บให้น้อยที่สุด แล้วคำนวณส่วนที่เหลือ

spec เสนอ type `IonClashLevel` ที่มีทั้ง `coefficients`, `reactantIonInstances`, `productIonInstances`, `spectatorIonIds`, `netIonic` ซึ่งถ้าเขียนมือครบ 50 ด่านจะยาวหลายพันบรรทัดและผิดง่ายมาก

**แผนนี้เก็บเฉพาะข้อมูลที่คำนวณไม่ได้** แล้วให้ Phase 1 คำนวณส่วนที่เหลือตอนโหลด

```ts
export type LevelSeed = {
  id: number;                                   // 1..50 คงที่ตลอดไป
  difficulty: 'easy' | 'basic' | 'medium' | 'hard' | 'challenge';
  reactantA: { cation: IonId; anion: IonId };
  reactantB: { cation: IonId; anion: IonId };
  hints: [string, string, string];              // 3 ระดับตาม D-05
};

export function buildLevel(seed: LevelSeed): BuiltLevel;
```

`buildLevel` คำนวณให้ทั้งหมด: สูตรสารตั้งต้น · ผลิตภัณฑ์จากการแลกคู่ · สถานะ aq/s จากตารางกฎ · สัมประสิทธิ์จากการดุล · ion instances · ไอออนผู้ชม · สมการสุทธิ

**กำไรที่ได้:** แก้กฎการละลายที่เดียว ด่านทั้ง 50 อัปเดตตาม · เพิ่มด่านใหม่เขียนแค่ 5 บรรทัด · เป็นไปไม่ได้ที่ข้อมูลจะขัดแย้งกันเอง

> `id` คือตัวตนถาวร ห้ามเปลี่ยนเลขเมื่อสลับลำดับในไฟล์ เพราะไฟล์ save ของนักเรียนอ้างอิงเลขนี้

## 2.3 จุดที่ต้องให้อาจารย์ตัดสิน

ร่างข้างบนใช้กฎการละลายระดับ ม.4 แบบมาตรฐาน แต่มีสารบางตัวที่ตำราคนละเล่มจัดไม่เหมือนกัน ต้องให้ผู้เชี่ยวชาญชี้ขาดก่อนใช้จริง

| สาร | ประเด็น | ด่านที่กระทบ |
|---|---|---|
| PbCl2 | ละลายน้อย ไม่ใช่ไม่ละลายสนิท ละลายได้มากขึ้นในน้ำร้อน | 14 |
| PbSO4 | ตำราส่วนใหญ่จัดเป็นตะกอน แต่บางเล่มเรียกละลายน้อย | 20 |
| CaSO4 | ละลายน้อย เส้นแบ่งไม่ชัด | ไม่ได้ใช้ในร่างนี้ |
| MgCO3 | ละลายน้อย บางตำราจัดเป็นละลาย | 18 |
| Ag2SO4 | ละลายน้อย | ไม่ได้ใช้ในร่างนี้ |
| FeS, CuS | ถูกต้องว่าเป็นตะกอน แต่ S2- ในน้ำเกิดไฮโดรลิซิสบางส่วน | 19, 38 |
| Fe(OH)2 | ถูกออกซิไดซ์เป็น Fe(OH)3 ได้ในอากาศ | 26, 27 |

> ถ้าอาจารย์ตัดสารใดออก ให้แทนที่ด้วยด่านสำรองจากไอออนชุดเดิม แล้ว**คงเลข id เดิมไว้** ห้ามเลื่อนเลขด่าน

## 2.4 เอกสารส่งอาจารย์ตรวจ

สร้างสคริปต์ที่ generate ไฟล์นี้จากข้อมูลจริง ไม่ใช่พิมพ์มือ เพื่อให้สิ่งที่อาจารย์เซ็นตรงกับสิ่งที่โปรแกรมใช้จริง 100%

`npm run gen:review` -> `docs/chemistry-review.md`

แต่ละด่านต้องแสดง

1. เลขด่านและระดับความยาก
2. สมการโมเลกุลที่ดุลแล้ว
3. สมการไอออนิกสมบูรณ์
4. สมการไอออนิกสุทธิ
5. ตะกอนและเหตุผลว่าเข้ากฎข้อไหน
6. ไอออนผู้ชม
7. คำใบ้ทั้ง 3 ระดับ
8. ช่องให้ติ๊ก ผ่าน / แก้ไข / ตัดออก

ท้ายเอกสารมีตารางกฎการละลาย 11 ข้อจากข้อ 1.2 และช่องลงชื่อผู้ตรวจพร้อมวันที่

## 2.5 Validation อัตโนมัติ

`src/data/levels.test.ts` ต้องวนทดสอบครบทั้ง 50 ด่านในลูปเดียว ตามที่ spec กำหนด

| # | กฎ | ทำไมสำคัญ |
|---|---|---|
| 1 | มี id ครบ 1 ถึง 50 ไม่ซ้ำ ไม่ขาด | AC-01 |
| 2 | สารตั้งต้นทั้งสองตัวเป็น (aq) | ถ้าเป็น (s) แปลว่าโจทย์ผิด |
| 3 | ผลิตภัณฑ์เป็นตะกอน **ตรง 1 ตัว** | MVP กำหนดไว้ ถ้าได้ 0 หรือ 2 ต้อง fail |
| 4 | ผลิตภัณฑ์อีกตัวละลายน้ำ | ต้องแตกเป็นไอออนในสมการสมบูรณ์ได้ |
| 5 | สมการดุลแล้วและเป็นอัตราส่วนต่ำสุด | AC-07 |
| 6 | จำนวนอะตอมทุกธาตุเท่ากันสองข้าง | ใช้ฟิลด์ `atoms` |
| 7 | ประจุรวมสองข้างเท่ากัน | ทั้งสมการสมบูรณ์และสุทธิ |
| 8 | ไอออนผู้ชมปรากฏสองข้างจำนวนเท่ากัน | AC-06 |
| 9 | ระดับความยากตรงกับความซับซ้อนจริง | ดูเกณฑ์ข้างล่าง |
| 10 | มีคำใบ้ครบ 3 ระดับ ไม่มีข้อความว่าง | D-05 |
| 11 | คำใบ้ไม่มีสูตรของผลิตภัณฑ์ตะกอนอยู่ในข้อความ | กันการเฉลยโดยไม่ตั้งใจ |
| 12 | **สมการสุทธิลดเป็นอัตราส่วนต่ำสุดแยกจากสมการโมเลกุล** | ดูคำอธิบายข้างล่าง |

**เกณฑ์ตรวจระดับความยากอัตโนมัติ**

| ระดับ | เงื่อนไข |
|---|---|
| `easy` | ประจุทุกไอออนเป็น ±1 และสัมประสิทธิ์ทุกตัวเป็น 1 |
| `basic` | มีประจุ ±2 และสัมประสิทธิ์สูงสุดไม่เกิน 2 |
| `medium` | ต้องมีวงเล็บในสูตรผลิตภัณฑ์ตะกอน |
| `hard` | มีประจุ ±3 หรือสัมประสิทธิ์สูงสุดตั้งแต่ 3 ขึ้นไป |
| `challenge` | สัมประสิทธิ์สูงสุดตั้งแต่ 6 หรือมี PO4 3- |

**กฎข้อ 12 อธิบาย** สมการโมเลกุลกับสมการสุทธิลดอัตราส่วนแยกกัน ตัวอย่างด่าน 40

```
โมเลกุล:        Al2(SO4)3 + 3BaCl2 -> 3BaSO4 + 2AlCl3      (อัตราส่วนต่ำสุดแล้ว)
ไอออนิกสมบูรณ์:  2Al3+ + 3SO4 2- + 3Ba2+ + 6Cl- -> 3BaSO4(s) + 2Al3+ + 6Cl-
ตัดผู้ชม:        3Ba2+ + 3SO4 2- -> 3BaSO4(s)
สุทธิที่ถูกต้อง:   Ba2+ + SO4 2- -> BaSO4(s)                  (ต้องหารด้วย 3 อีกชั้น)
```

ด่านที่เข้าข่ายนี้คือ 35, 36, 40 และ 50 ถ้าลืมลดขั้นสุดท้าย ผู้เรียนจะเห็นสมการสุทธิผิดรูปแบบที่ตำราสอน

> กฎข้อ 11 สำคัญกว่าที่คิด เพราะคนเขียนคำใบ้เผลอพิมพ์ AgCl ลงไปได้ง่ายมาก แล้วเกมก็เฉลยคำตอบให้ฟรี

## กับดักที่ต้องระวัง

| กับดัก | ผลที่ตามมา |
|---|---|
| เขียน BuiltLevel ลงไฟล์แบบ hard-code | ข้อมูลจะขัดแย้งกับตรรกะเมื่อแก้กฎการละลาย ต้องคำนวณตอน runtime เท่านั้น |
| เปลี่ยนเลขด่านตอนแก้ข้อมูล | ไฟล์ save ของนักเรียนพัง ความก้าวหน้าหาย |
| ใส่คำใบ้ที่มีสูตรตะกอน | เฉลยคำตอบฟรี ขัด spec โดยตรง |
| ลืมว่าด่าน 40 ตะกอนมาจากคู่ที่ไม่มี Na/K | ด่านนี้ไอออนผู้ชมคือ Al3+ กับ Cl- ไม่ใช่ Na+ ตรวจให้ดี |
| คิดว่าด่าน 18, 19, 38 ไม่ต้องดุลเลยจึงง่าย | ประจุ ±2 ทั้งคู่ อัตราส่วน 1:1:1:1 แต่แนวคิดยากกว่าช่วง 01-10 จริง ต้องจัด `basic` ไม่ใช่ `easy` |
