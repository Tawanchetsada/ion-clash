## 7.2 Route guard

**ห้ามอาศัยแค่ทำปุ่มสีเทา** ถ้าเปิด URL ของด่านที่ยังล็อกโดยตรง ต้องพากลับ `/levels` พร้อมข้อความ "ผ่านด่านก่อนหน้าเพื่อปลดล็อกด่านนี้"

```
เข้า /level/25/play
   |
   +-- levelId ไม่ใช่เลข 1-50 --------> Not Found + ปุ่มกลับเลือกด่าน
   |
   +-- ยังไม่ mount (SSR) ------------> แสดง skeleton ห้ามอ่าน localStorage
   |
   +-- levelId > unlockedLevel -------> redirect /levels + toast
   |
   +-- ข้อมูลด่าน invalid ------------> แสดงรหัสข้อผิดพลาด ไม่ทำให้ทั้งเว็บล่ม
   |
   +-- ผ่านหมด ----------------------> เล่นได้
```

> guard ต้องทำงานหลัง mount เท่านั้น เพราะต้องอ่าน save จาก localStorage ซึ่งอ่านตอน SSR ไม่ได้ ระหว่างรอให้แสดง skeleton ไม่ใช่หน้าเปล่า

## 7.3 หน้าหลัก

- โลโก้ ION CLASH และคำอธิบาย "แยกไอออน • สร้างตะกอน • ตัดไอออนผู้ชม"
- ปุ่ม **เริ่มเกม** เด่นที่สุด สีทอง ไป `/levels`
- ปุ่ม **วิธีการเล่น** สีน้ำเงิน ไป `/how-to-play`
- ปุ่ม **ความรู้ก่อนเล่นเกม** สีเขียว ไป `/knowledge`
- **ครั้งแรกที่เข้า** กดเริ่มเกมแล้วขึ้นขั้นกรอกชื่อผู้เล่นก่อน ตาม D-14 พร้อมข้อความขอความยินยอมการเก็บข้อมูลวิจัย
- ถ้ามี save เดิม เปลี่ยนข้อความปุ่มหลักเป็น **เล่นต่อด่าน XX** และเพิ่มปุ่มรอง **เลือกด่าน** และไม่ถามชื่อซ้ำ
- โหลดความก้าวหน้าให้เสร็จก่อนแสดงปุ่ม เพื่อไม่ให้ข้อความปุ่มกระพริบเปลี่ยน

## 7.4 หน้าเลือกด่าน

- แบ่ง 5 ช่วง ช่วงละ 10 ด่าน คือ 01-10 ง่าย · 11-20 พื้นฐาน · 21-30 ปานกลาง · 31-40 ยาก · 41-50 ท้าทาย
- เริ่มต้นปลดเฉพาะด่าน 01
- แสดงความคืบหน้า เช่น 3/50 และจำนวนดาวรวม
- สถานะต้องต่างกันทั้ง**สีและสัญลักษณ์** ผ่านแล้วมีเครื่องหมายถูก ด่านปัจจุบันมีขอบเน้น ล็อกมีรูปกุญแจ
- เล่นด่านที่ผ่านแล้วซ้ำได้ ระบบเก็บเฉพาะผลที่ดีที่สุด

## 7.5 หน้าโจทย์ประจำด่าน

- แสดงสารตั้งต้น 2 ชนิดพร้อมสถานะ เช่น `NaCl(aq) + AgNO3(aq) -> ?`
- ใช้เครื่องหมาย `?` แทนผลิตภัณฑ์ **ห้ามเผยผลิตภัณฑ์ ไอออน หรือการ์ดสีทอง**
- ปุ่ม **เริ่มแยกไอออน** พาเข้าสู่ขั้น 1 ของ `/play`
- **เริ่มจับเวลาเมื่อกดปุ่ม** ไม่ใช่ตอนเข้า route
- กลับหน้าเลือกด่านได้ มี dialog ยืนยันเฉพาะเมื่อมี checkpoint ค้างอยู่

## 7.6 หน้าเล่นเกม 5 ขั้น

หน้าเดียวที่เรนเดอร์ต่างกันตาม `state.phase` โดยมี `StepIndicator` คงอยู่ตลอด

| ขั้น | phase ที่เกี่ยวข้อง | สิ่งที่แสดง |
|---|---|---|
| 1 | `dissociateReactants` | สมการโจทย์ + ไอออนสารตั้งต้น 4 ใบ |
| 2 | `arrangeProductIons` และ `balanceEquation` | ช่องวาง 4 ช่อง + ช่องสัมประสิทธิ์ (ถ้าต้องดุล) |
| 3 | `validateProducts` | กล่อง "เกิดตะกอน" และ "ยังคงอยู่ในสารละลาย" |
| 4 | `cancelSpectatorIons` | สมการไอออนิกสมบูรณ์ + เส้นตัด |
| 5 | `netIonicResult` และ `levelComplete` | สมการสุทธิ + คะแนน + ดาว + ปุ่มไปต่อ |

**ขั้น 3 ตาม UI PDF หน้า 9** แยกเป็นสองกล่องชัดเจน กล่องซ้ายคือตะกอนสีทอง กล่องขวาคือไอออนที่ยังละลายอยู่เป็นสีน้ำเงินกับเขียว

**ขั้น 5 ต้องแสดง SaveStatus ก่อนเปิดปุ่มไปต่อ** ถ้าบันทึกไม่ได้ ผู้เล่นยังผ่านด่านใน session แต่ต้องเห็นคำเตือนและปุ่มลองบันทึกอีกครั้งหรือส่งออกข้อมูล

## 7.7 หน้าความก้าวหน้าและตั้งค่า

**`/progress`** สรุปด่านที่ผ่าน ดาวรวม คะแนนรวม เวลาที่ใช้ พร้อมปุ่ม export · import · reset

**`/settings`** สลับเสียง เพลง ลดการเคลื่อนไหว และลิงก์ไปจัดการข้อมูลบนเครื่อง

ทั้งสองหน้าต้องมีคำเตือนชัดเจนว่าข้อมูลอยู่ในเบราว์เซอร์เครื่องนี้ ไม่ซิงก์ข้ามอุปกรณ์ และอาจหายเมื่อล้างข้อมูลเว็บไซต์

---

## 7.8 สถานะพิเศษที่ต้องรองรับ

| กรณี | พฤติกรรม |
|---|---|
| Level ID ไม่มีอยู่ | Not Found + ปุ่มกลับหน้าเลือกด่าน |
| ด่านยังล็อก | redirect `/levels` + toast บอกด่านที่ต้องผ่าน |
| ข้อมูลด่าน invalid | ไม่เปิดเกม แสดงรหัสข้อผิดพลาดที่นักพัฒนาตามได้ ไม่ทำให้ทั้งเว็บล่ม |
| Save JSON เสีย | สร้าง backup corrupt ใช้ default save แจ้งผู้ใช้ เสนอ import |
| Storage ถูกปิดกั้น | เล่นได้ใน session แสดง save error แบบไม่บังเกม มีปุ่ม export |
| Refresh กลางด่าน | โหลด checkpoint ล่าสุด ถ้าไม่มีให้กลับ intro โดยไม่เพิ่ม attempt |
| เปิดหลายแท็บ | merge best progress ห้ามให้ `unlockedLevel` ลดลง |

## กับดักที่ต้องระวัง

| กับดัก | ผลที่ตามมา |

| อ่าน save ตอน SSR | หน้าพังทันที ต้องอ่านใน effect หลัง mount |

| เริ่มจับเวลาตอนเข้า route | เวลาเพี้ยนถ้าผู้เล่นอ่านโจทย์นาน กระทบข้อมูลวิจัย |
