# ข้อสันนิษฐานและการเปลี่ยนแปลงจากข้อกำหนด (Assumptions & Deviations)

เอกสารฉบับนี้รวบรวมรายการข้อสันนิษฐาน การปรับปรุง และความแตกต่างระหว่างระบบเว็บ Ion Clash กับข้อกำหนดเดิม (`Ion_Clash-frontend-requirements_spec.md`) และสำรับการ์ดกายภาพ เพื่อใช้เป็นหลักฐานประกอบการเขียนเล่มวิทยานิพนธ์

---

## 1. การเปรียบเทียบสำรับการ์ดกายภาพกับระบบเว็บ (D-02, D-16)

สำรับการ์ดกายภาพ 10×10 เดิมมีข้อจำกัดทางเคมีบางประการ ระบบเว็บจึงได้ปรับปรุงทะเบียนไอออน 22 ตัว (12 แคตไอออน + 10 แอนไอออน) ดังตารางเปรียบเทียบ:

| ไอออน | มีในสำรับการ์ด | มีในระบบเว็บ | เหตุผลทางวิชาการ |
|---|:---:|:---:|---|
| **Na⁺, K⁺, NH₄⁺, Ag⁺, Ca²⁺, Mg²⁺, Cu²⁺, Fe²⁺, Fe³⁺, Al³⁺** | ✓ | ✓ | เป็นไอออนหลักตามหลักสูตรเคมี ม.4 |
| **Pb²⁺ (เลด(II))** | ✗ | ✓ | เพิ่มเพื่อให้เกิดตะกอน PbI₂ (สีเหลือง), PbSO₄, PbCl₂ ตามตัวอย่างใน UI Reference |
| **Ba²⁺ (แบเรียม)** | ✗ | ✓ | เพิ่มเพื่อให้เกิดตะกอน BaSO₄ ซึ่งเป็นตะกอนมาตรฐานที่สำคัญที่สุดในหลักสูตร |
| **NO₃⁻, Cl⁻, OH⁻, SCN⁻, SO₄²⁻, CO₃²⁻, PO₄³⁻** | ✓ | ✓ | แอนไอออนมาตรฐานตามหลักสูตร ม.4 |
| **Br⁻ (โบรไมด์), I⁻ (ไอโอไดด์)** | ✗ | ✓ | เพิ่มเพื่อจับคู่กับ Ag⁺ และ Pb²⁺ ตามกฎการละลายเฮไลด์ (กฎข้อ 3) |
| **S²⁻ (ซัลไฟด์)** | ✗ | ✓ | เพิ่มเพื่อจับคู่กับ Cu²⁺, Fe²⁺, Ag⁺ ให้เกิดตะกอนซัลไฟด์สีดำ |
| **O²⁻ (ออกไซด์)** | ✓ | **ตัดออก** | **ผิดหลักเคมี:** O²⁻(aq) อยู่ในน้ำไม่ได้ จะเกิดปฏิกิริยาไฮโดรไลซิสเป็น OH⁻ ทันที จึงไม่สามารถตกตะกอนเป็น Al₂O₃ จากสารละลายน้ำได้ |
| **MnO₄²⁻ (แมงกาเนต)** | ✓ | **ตัดออก** | ไม่อยู่ในหลักสูตร ม.4 และไม่เสถียรในน้ำ (ตัวที่นักเรียนเรียนคือ MnO₄⁻ เปอร์แมงกาเนต) |
| **CN⁻ (ไซยาไนด์)** | ✓ | **ตัดออก** | เป็นสารพิษร้ายแรงและตะกอนไซยาไนด์ไม่อยู่ในหลักสูตร ม.4 |

## 2. การเก็บข้อมูลชื่อผู้เล่น (D-14)

- **สเปกเดิม:** ระบุว่า "ไม่เก็บชื่อ โรงเรียน อีเมล หรือข้อมูลส่วนบุคคลใน MVP"
- **การเปลี่ยนแปลงในระบบเว็บ:** เพิ่มหน้ากรอกชื่อผู้เล่นก่อนเริ่มเกม โดยเก็บลงใน `GameSaveV1.playerName` และแนบไปกับข้อมูลวิจัยทุก Event
- **เหตุผล:** เพื่อให้ผู้วิจัยสามารถจำแนกและวิเคราะห์ข้อมูลผลการเรียนรู้ของกลุ่มตัวอย่างรายบุคคลได้ และแนะนำให้ผู้เรียนใช้ชื่อเล่นหรือรหัสนักเรียนแทนชื่อ-นามสกุลจริง

---

## 3. แผงตารางกฎการละลายน้ำระหว่างเล่นเกม (Phase 8 Step 6)

- **สเปกเดิม:** ไม่มีปุ่มเปิดดูกฎการละลายในหน้าระหว่างเล่นเกม (มีเฉพาะปุ่มคำใบ้)
- **การเปลี่ยนแปลงในระบบเว็บ:** เพิ่มปุ่ม "ดูกฎการละลาย" ในหน้าเล่นเกม (`/level/[levelId]/play`) เพื่อเปิด `SolubilityDialog` แสดงตารางกฎ 11 ข้อ
- **เหตุผล:** นักเรียนชั้น ม.4 ยังไม่สามารถจดจำกฎการละลายน้ำทั้ง 11 ข้อได้ทั้งหมด หากไม่มีตารางอ้างอิง เกมจะกลายเป็นการทดสอบความจำแทนที่จะเป็นการทดสอบความเข้าใจเชิงกระบวนการคิด ซึ่งขัดกับวัตถุประสงค์งานวิจัย
- **กติกาควบคุม:** การเปิดดูกฎการละลาย **ไม่หักคะแนน** และ **ไม่มีการไฮไลต์เฉลยแถวที่ตรงกับด่านปัจจุบัน**

---

## 4. สถานะสารละลายน้อย (Slightly Soluble Compounds) (D-15)

- สารอย่าง $PbCl_2$, $PbSO_4$, $MgCO_3$, $Fe(OH)_2$ จัดเป็นตะกอน $(s)$ ตามตำราเรียนเคมีระดับ ม.4 ของ สสวท.
- สาร $CuCO_3$ ตัดออกและเปลี่ยนเป็น $Ag_2S$ (ด่าน 39) เนื่องจากในสารละลายน้ำจริงจะได้ basic copper carbonate

---

## 5. การส่งข้อมูลออกเครือข่ายและระบบเก็บข้อมูลวิจัย (D-06, D-07, D-12, D-13, D-14)

- **สเปกเดิม:** ระบุว่าเป็นเว็บ client-only ไม่ส่งข้อมูลออกภายนอก
- **การเปลี่ยนแปลงในระบบเว็บ:**
  1. เพิ่มระบบจัดเก็บข้อมูลวิจัยสองทาง (Dual Sink): `LocalSink` (ในเครื่อง) และ `RemoteSink` (ยิง POST รายด่านไปยัง Google Apps Script Web App เพื่อบันทึกลง Google Sheet)
  2. มีหน้าต่างขอความยินยอม (Consent) จากผู้เรียนก่อนเริ่มเกม และสามารถเปิด/ปิดได้ใน `/settings` หากไม่ยินยอมจะปิด `RemoteSink` ทันทีแต่ยังเล่นเกมและส่งออกไฟล์ในเครื่องได้ตามปกติ
  3. ไม่เก็บข้อมูลระบุตัวบุคคล (PII) เช่น ชื่อจริงเต็ม โรงเรียน หรืออีเมล
  4. การคำนวณ $E_1$ (คะแนนระหว่างเรียน) ใช้คะแนนเกม 0–100 ที่หักคำใบ้และการตอบผิดแล้ว และคิดสะสมรายด่านที่เล่นจบจริง (D-12, D-13)
  5. การคำนวณ $E_2$ (คะแนนหลังเรียน) ให้ผู้วิจัยนำคะแนนจากแบบทดสอบกระดาษมากรอกในหน้า `/research` เพื่อประเมินผลเทียบเกณฑ์ 80/80 (D-07)
